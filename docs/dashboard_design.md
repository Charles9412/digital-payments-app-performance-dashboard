# Dashboard Design

The dashboard is designed for executive monitoring with a clear top-to-bottom information flow.

## Layout
- Top section: dashboard title and date filter controls
- Left section: KPI summary cards for high-level performance tracking
- Right section: monthly trend charts for contracts and registered users
- Lower section: regional adoption map highlighting state-level variation

## Visual Style
- Dark executive visual style to improve contrast and dashboard focus
- Compact, high-signal layout intended for quick business reviews
- Portfolio-safe design that supports public sharing with synthetic data
